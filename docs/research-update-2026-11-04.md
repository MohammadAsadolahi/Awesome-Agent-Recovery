# Research update — 4 November 2026: directly relevant agent failure publications

**Selection:** 15 original research publications added to the existing 116-resource index (**131 total**). Every addition is `kind=paper`; **no** standalone software project, benchmark repository, tutorial, survey list or general-purpose framework was added. Companion code is linked only as supporting evidence within the corresponding paper record.

**Methods:** Compared candidate titles, persistent identifiers and canonical URLs with the repository's CSV/JSON index on 4 November 2026. Screened scholarly publisher proceedings, arXiv primary abstracts/full texts, and author-maintained paper repositories where available. Required a central contribution directly about **agent failure, diagnosis, self-recovery, targeted repair, fault-specific evaluation, or recovery verification**. Publication status is explicit: proceedings papers are distinct from preprints and workshops. Performance numbers below are **author-reported**, not independently replicated.

## Why these are nonduplicate

- **MAST / AgentFail / TraceElephant / MP-Bench** add, respectively, a published failure taxonomy, *platform-orchestrated* traces, **full-input observability**, and **ambiguous/multiple valid attributions**. They are not the same benchmark or the same unit of measurement as the existing **AgentRx**, **EDGE**, **TRAJDEBUG** or **DoCtOR** entries.
- **AgentDebug** is the original error taxonomy, benchmark and repair-feedback research; **AgentDebugX** is a later toolkit and Detect–Attribute–Recover–Rerun demonstration. One canonical publication is linked for each, with the distinction explicit.
- **AgentTrace / VerifyMAS / DeFA / AgentForesight** make different causal and temporal claims: fast post-hoc structural analysis; hypothesis validation; dependency propagation; and prefix-only **online** risk detection. None is labeled a successful intervention unless subsequent state is independently checked.
- **Self-Direction** converts lessons from failed runs into routed, persistent lightweight adapters; unlike **Sentry** (conditionally supplied text lessons) or **Agent-Reflex** (trained reflective base behavior), it tests the cost and reusability of independently stored parameter adapters.
- **Fail-Fast, Restart-Smart** tests cost-sensitive early stopping and **same-policy** restart with optionally retained diffs, distinct from generic retries, checkpoint restoration and evaluator-only monitor scores.
- **LAST-CQ** quantifies whether corrected task success comes from recovery triggering versus elaborate feedback and sampling, adding database-grounded ablations rather than merely another tool-use benchmark.
- **TraceFix** is repair of **coordination protocol specifications** under model-checker counterexamples, not restoration of all agent or external state.
- **Recova** is explicitly about restoring physical task progress after failed embodied actions, unlike the repository's software/GUI checkpoint cases. **Hardware-fault resilience** studies spontaneous agent recovery under model-weight faults rather than ordinary tool-error injection.

## Evidence-oriented reading path

1. **Define the failure:** use MAST, AgentFail and AgentDebug to name which layer failed and whether an observed symptom is the cause.
2. **Attribute with appropriate observability:** use TraceElephant, MP-Bench, VerifyMAS, DeFA or AgentTrace, noting attribution ambiguity and partial logs.
3. **Decide when to intervene:** compare AgentForesight and Fail-Fast on false alarms, online observability, time/cost and the risk of terminating a trajectory that would have recovered naturally.
4. **Choose bounded repair:** TraceFix for *coordination specifications*, LAST-CQ for *query-generation retries*, Recova for *restoring physical robot state*, and Self-Direction for *reducing repeated mistakes across future tasks*.
5. **Verify independently:** log task postconditions and external state where applicable. Neither root-cause accuracy, model-checker success, nor reflection-lesson transfer proves a remote effect was undone.

## Deferred or excluded by the publication-only, failure-specific rule

- [Beyond Prompts: Measuring and Optimizing LLM Tool-Agent Harnesses](https://aclanthology.org/2026.findings-emnlp.1455/) — a legitimate scholarly paper but primarily **general harness optimization**, only partly about failure handling; not admitted.
- [LLM Agents as Resilience Engineers for Scientific Applications](https://arxiv.org/abs/2610.11260) — agents synthesizing checkpoint/restart for **other MPI programs**, rather than studies of recovering the AI agent's own failed task; excluded.
- [Local Solution Repair for Multi-Agent Pickup and Delivery](https://arxiv.org/abs/2611.02090) — valid multi-robot routing optimization, but not about failures of an LLM/AI agent or recovery after execution fault in this collection's sense.
- Generic agent surveys, code repositories without separately identifiable research publications, duplicate arXiv/proceedings versions, and broad accuracy or prompt-engineering studies without failure-specific evaluation.
